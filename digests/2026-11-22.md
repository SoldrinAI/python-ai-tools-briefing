# AI tools and libraries on Python: 2026-11-22

It's a quiet day, and most of what shipped in the last 48 hours is open source. The useful items are a transformers release with a rename that will touch custom cache code, a pre-release of the OpenAI Agents SDK that can run Codex, and two FastMCP releases that include an OAuth fix.

## Enterprise tools

Nothing from Azure, AWS, Google Cloud, Databricks, Snowflake or NVIDIA that I could verify landed inside the window. Google's ADK 2.15.0 shipped on Nov 19, right at the edge, and Anthropic's Python SDK 2.12.0 came out on Nov 20 but was already in yesterday's digest, so I've left both out.

## Open source libraries

**[transformers v5.24.0](https://github.com/huggingface/transformers/releases/tag/v5.24.0)** (Nov 21). The headline is about ten new model families, including Inkling 2 Mini, Apertus 1.5, Dory and Omnilingual ASR. The change that will bite custom code is the cache rename: `past_key_values` and `cache_params` are now `cache` across the library. The old names still work with a deprecation warning, but passing both raises a `ValueError`. The release also requires `peft>=0.22.0`.

```bash
pip install -U "transformers==5.24.0" "peft>=0.22.0"
```

**[OpenAI Agents SDK v1.0.0-alpha.1](https://github.com/openai/openai-agents-python/releases/tag/v1.0.0-alpha.1)** (Nov 20). This is a pre-release that adds Codex as an opt-in model provider. The wheel embeds Codex Core, so calls skip the `codex app-server` startup. It also lets you pause for approval before a Python tool runs. The wheels are only on GitHub Releases for now, and the notes list several caveats, so read them before you try it on anything shared.

```python
from agents.models.codex import CodexProvider

provider = CodexProvider()  # uses your saved Codex login unless you pass an API key
```

**[FastMCP v4.2.4 and v4.2.3](https://github.com/PrefectHQ/fastmcp/releases/tag/v4.2.4)** (Nov 20 and 21). The v4.2.4 fix matters if you run an OAuth proxy. A race let concurrent requests redeem one authorization code or refresh token twice, and revoked access tokens could come back after a refresh. v4.2.3 adds an opt-in `parent_task_spans` setting that nests background task spans under `tools/call`, which helps when you trace tool calls.

```bash
pip install -U fastmcp==4.2.4
```

**[LangGraph 1.2.24](https://github.com/langchain-ai/langgraph/releases/tag/1.2.24)** (Nov 20). A small one. `REMOVE_ALL_MESSAGES` is now handled in the messages delta reducer, and `None` checkpoints in DeltaChannel are handled too. If you use message reducers with DeltaChannel, it's worth picking up.

```bash
pip install -U langgraph==1.2.24
```

## Worth trying today

If you run FastMCP with an OAuth proxy, install 4.2.4 in a scratch environment and run your auth tests against it before touching anything shared. That's the release most likely to change how your tokens behave.

```bash
python -m venv .venv-fastmcp && . .venv-fastmcp/bin/activate
pip install -U fastmcp==4.2.4
```
