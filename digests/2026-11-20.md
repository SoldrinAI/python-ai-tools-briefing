# AI tools and libraries on Python: 2026-11-20

Yesterday's batch covered November 18, so this one is mostly what landed on November 19 and the early hours of today. Most of it is point releases, but the Databricks enum removal and the ADK builder removal are the two that can break a build.

## Enterprise tools

**[Anthropic Python SDK v2.11.0](https://github.com/anthropics/anthropic-sdk-python/releases/tag/v2.11.0)** (Nov 19). The additions are Claude Code managed settings in the Admin API and a new `sandbox_egress_restricted` error on the plugin methods. The fix to read if you call Claude through Bedrock is in the request encoding: spaces in query strings now go out as `%20`, which fixes SigV4 signature mismatches on those requests. No breaking changes are listed.

```bash
pip install -U anthropic==2.11.0
```

**[OpenAI Python SDK v3.56.0](https://github.com/openai/openai-python/releases/tag/v3.56.0)** (Nov 19). This is a small one. It adds `gpt-live-1.1` as a choice in the Live model options and nothing else that changes request shapes. No breaking changes or deprecations are listed.

```bash
pip install -U openai==3.56.0
```

**[Databricks SDK for Python v0.169.0](https://github.com/databricks/databricks-sdk-py/releases/tag/v0.169.0)** (Nov 19). It adds `delete_software_artifact()` and `delete_software_artifact_version()` on `w.software_artifacts`, plus a `high` value for AI runtime task priority. Read the breaking part first: `best_effort` has been removed from `AiRuntimeTaskPriorityClass`, so code that references it will need updating.

```bash
pip install -U databricks-sdk==0.169.0
```

**[Snowpark Python v1.58.0](https://github.com/snowflakedb/snowpark-python/releases/tag/v1.58.0)** (Nov 19). The `DataFrameReader.documents()` reads that use a `schema` or a `prompt` now return per-document token counts from `AI_COMPLETE`, in `INPUT_TOKENS` and `OUTPUT_TOKENS` columns. That feature is still in Private Preview. If you already have a schema field with one of those two names, rename it before you upgrade.

```bash
pip install -U snowflake-snowpark-python==1.58.0
```

## Open source libraries

**[pydantic-ai 2.71.0](https://github.com/pydantic/pydantic-ai/releases/tag/v2.71.0)** (published Nov 19). This is a busy release. The one to check first is the rename of `PeerNetwork` to `PeerConnection`, so anything importing the old name needs changing. It also adds a batch of harness capabilities, including `Goal`, `RequireVerification` and `WrapUpAtLimits`, plus a `ModelRouter` for agent runs.

```bash
pip install -U pydantic-ai==2.71.0
```

**[Google ADK Python v2.15.0](https://github.com/google/adk-python/releases/tag/v2.15.0)** (Nov 19). The Visual Agent Builder is gone from ADK Web, along with its `/builder` routes. Agents built with it are still standard Agent Config YAML files, so they are not stranded. On the evaluation side there are new `pass@k` and `pass^k` metrics, which tell you whether an agent solves a task at least once versus on every run. `McpInstructionProvider` no longer fills prompt arguments from session state, so pass `arguments=` explicitly.

```bash
pip install -U google-adk==2.15.0
```

**[LangGraph 1.2.23](https://github.com/langchain-ai/langgraph/releases/tag/1.2.23)** (Nov 19). A bug-fix release, but it matters if you dispatch tool calls with `Send`. Those calls now receive the same state an edge would give them. The companion `langgraph-prebuilt` 1.1.3 carries the same fix, and it also makes `wrap_tool_call` state overrides reach the tool. No breaking changes are listed.

```bash
pip install -U langgraph==1.2.23
```

## Worth trying today

Yesterday's grep looked for names that were removed. Today's version looks for the ones these releases renamed or dropped. Run it from the root of a project, then upgrade on a branch so you can see what breaks.

```bash
grep -rnE "best_effort|PeerNetwork|McpInstructionProvider" --include="*.py" .
```
