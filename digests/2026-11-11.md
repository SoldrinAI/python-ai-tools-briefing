# AI tools and libraries on Python: 2026-11-11

It was a light two days, mostly point releases from SDK maintainers tidying up provider clients. The changes that can affect running code are in the Anthropic, Databricks and pydantic-ai updates, so start there.

## Enterprise tools

**[anthropic 2.8.0](https://github.com/anthropics/anthropic-sdk-python/releases/tag/v2.8.0)** (Nov 10). The main additions are Claude Tag metrics in the analytics summaries and a `reply_mode` setting for Claude Tag Slack channels. For code that calls Claude through Bedrock or Vertex, the more useful part is the validation fixes. Empty project, region or model values are now refused instead of being written into the request path, and a `;` in a model ID is handled differently. If your client builds paths from config values, test one empty value.

```bash
pip install -U "anthropic==2.8.0"
```

**[databricks-sdk 0.164.0](https://github.com/databricks/databricks-sdk-py/releases/tag/v0.164.0)** (Nov 10). Most of this release is new fields on `ml.Feature`, `postgres.CdfConfig` and `postgres.GenerateDatabaseCredentialRequest`. The one to check is `notebook_content` on `cleanrooms.CleanRoomAssetNotebook`, which is now optional. The release flags that as a breaking change, so guard any code that reads it.

```bash
pip install -U "databricks-sdk==0.164.0"
```

**[google-genai 3.1.0](https://github.com/googleapis/python-genai/releases/tag/v3.1.0)** (Nov 10). It adds `gemini-omni-1.2-flash`, which is now the default model for video on the Gemini API, plus a `proactive_video` option in `ProactivityConfig` for the Live API. Embedding responses also gain usage metadata for the Gemini Enterprise API, which helps if you track usage per call.

```bash
pip install -U "google-genai==3.1.0"
```

## Open source libraries

**[pydantic-ai 2.67.0](https://github.com/pydantic/pydantic-ai/releases/tag/v2.67.0)** (Nov 10). The one to read before upgrading is the instruction loading change. `RepoContext` now loads one instruction file per directory by default, and nested instructions are capped at 32,000 characters. Provider-specific native tool fields have also moved to `provider_settings`. On the feature side, it adds support for Claude Fable 5.2 and Claude Mythos 5.2, and `dequeue` for queued messages.

```bash
pip install -U "pydantic-ai==2.67.0"
```

**[litellm 1.108.5](https://pypi.org/project/litellm/1.108.5/)** (Nov 10). GitHub marks this as the LTS release. I could not pull its change list in this run, so read the GitHub release page before you move a production install to it.

```bash
pip install -U "litellm==1.108.5"
```

## Worth trying today

Check whether your pins still resolve against the new releases without touching your environment:

```bash
pip install --dry-run -U "anthropic==2.8.0" "pydantic-ai==2.67.0" "litellm==1.108.5"
```

If pip reports a conflict, you know which pin to revisit before the next deploy.
