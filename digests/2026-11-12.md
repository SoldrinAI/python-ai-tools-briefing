# AI tools and libraries on Python: 2026-11-12

Most of the movement in the last two days is SDK releases, and one of them is a bigger deal than its version number suggests. DSPy 3.5.0 changes default behavior in ways that can shift your prompts, so it is the one to read first.

## Enterprise tools

**[google-genai 3.2.0](https://github.com/googleapis/python-genai/releases/tag/v3.2.0)** (Nov 11). This adds a `decisions` resource (`client.decisions.create`) and a self-hosted BYOS mode for environments, with system instruction and custom config support in both the SDK and the CLI. The release notes list no breaking changes. If you build agents on Gemini and want to record decisions, the new resource is the thing to try.

```bash
pip install -U "google-genai==3.2.0"
```

**[bedrock-agentcore 1.26.0](https://github.com/aws/bedrock-agentcore-sdk-python/releases/tag/v1.26.0)** (Nov 10). `WebSearchClient` now calls the Web Search API through `InvokeWebSearch`. If you wrote your own search wrapper for agents running on AgentCore, compare it against this before you keep maintaining it.

```bash
pip install -U "bedrock-agentcore==1.26.0"
```

**[databricks-sdk 0.165.0](https://github.com/databricks/databricks-sdk-py/releases/tag/v0.165.0)** (Nov 11). This is one release after yesterday's 0.164.0. It adds a `pt_term` field to the serving `PtServedModel` class. It also removes `custom_content_pack_path` and `custom_presets_path` from the lakewatch `CommonConfig`, so grep your code for both names before you upgrade.

```bash
pip install -U "databricks-sdk==0.165.0"
```

## Open source libraries

**[DSPy 3.5.0](https://github.com/stanfordnlp/dspy/releases/tag/3.5.0)** (Nov 10). The XML adapter is now the default, so prompts can change even when your Signature stays the same. LiteLLM and the OpenAI SDK are now optional, and providers run through a bundled engine instead. `CodeAct` and `ProgramOfThought` are gone, and `ReActV2` is now `dspy.ReAct`. The maintainers say to re-evaluate optimized programs after upgrading, and that is good advice. The reported default install size drops from 206.7 MiB to 30.9 MiB.

```bash
pip install -U "dspy==3.5.0"
```

**[langchain-core 1.8.0](https://github.com/langchain-ai/langchain/releases/tag/langchain-core%3D%3D1.8.0)** (Nov 11). It adds decision models and drops Python 3.10, so the minimum is now 3.11. If you are still on 3.10, the release notes say to stay on the 1.7.x line.

```bash
pip install -U "langchain-core==1.8.0"
```

**[crewAI 1.15.40](https://github.com/crewAIInc/crewAI/releases/tag/1.15.40)** (Nov 11). The fix that matters is that `after_llm_call` hooks now run on async calls. If you rely on that hook in async flows, you were probably missing calls before. The release also removes ChromaDB from the embedding function layer, so check that you are not relying on it there.

```bash
pip install -U "crewai==1.15.40"
```

## Worth trying today

Pick one DSPy program you already optimized, save it, then run your eval set against 3.4 and against 3.5 in separate virtualenvs and compare the scores.

```bash
python -m venv .venv-dspy && . .venv-dspy/bin/activate && pip install "dspy==3.5.0"
```

If the numbers move, you have your answer before the change reaches production.
