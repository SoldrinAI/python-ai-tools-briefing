# AI tools and libraries on Python: 2026-11-21

It's a quiet read today: most of what shipped in the last two days was already in yesterday's digest. What's left is two enterprise SDK updates and two open source releases, and I couldn't verify anything new from Azure, Google Cloud or NVIDIA in that window.

## Enterprise tools

**[Anthropic Python SDK v2.12.0](https://github.com/anthropics/anthropic-sdk-python/releases/tag/v2.12.0)** (Nov 20). The fix that matters is for Bedrock. `AnthropicBedrock` and `AsyncAnthropicBedrock` were dropping profile IDs, because Bedrock reads `user_profile_id` from the request body and ignores the header. The clients now send it in the body. The catch is that some Bedrock models don't support user profiles, and a request to one of them with a profile ID now fails with a 400 instead of being silently ignored, so take the ID off those calls.

```bash
pip install -U anthropic==2.12.0
```

**[OpenAI Python SDK v3.57.0](https://github.com/openai/openai-python/releases/tag/v3.57.0)** (Nov 20). This one is small. The only listed change is Live WebRTC standby support, with no new methods, models or breaking changes named. It only matters if you use the Live API.

```bash
pip install -U openai==3.57.0
```

## Open source libraries

**[LiteLLM v1.110.2](https://github.com/BerriAI/litellm/releases/tag/v1.110.2)** (Nov 20). This is a patch release with eight fixes, and the notes say no action is needed to upgrade. If you call Claude through LiteLLM, the one to check is `temperature=1`, which was returning a 400 on Claude models that no longer accept sampling parameters. The release also fixes a `/key/info` issue where a key with no user could read other userless keys, and a streaming retry problem that could send duplicate events and bill extra calls.

```bash
pip install -U litellm==1.110.2
```

**[langchain-core 1.8.4](https://github.com/langchain-ai/langchain/releases/tag/langchain-core==1.8.4)** (Nov 19). Two changes here. Finish reasons are now standardized on message-finish events, and synthetic human-in-the-loop tool messages carry source metadata. Both show up when you parse stream events or audit what an agent did on its own. The notes list no breaking changes, but they don't spell out the new field names, so read PRs #41926 and #41928 before you depend on them.

```bash
pip install -U langchain-core==1.8.4
```

## Worth trying today

If you run LiteLLM with Claude, check the `temperature=1` case in a throwaway environment so your project stays untouched.

```bash
python -m venv .venv-litellm && . .venv-litellm/bin/activate
pip install -U litellm==1.110.2
python -c "import litellm; print(litellm.__version__)"
```
