# AI tools and libraries on Python: 2026-11-16

Another quiet stretch. Most of what I could verify landed on November 13, which is at or past the edge of a strict 48-hour window, so I've dated each item and kept the list short.

## Enterprise tools

**[Microsoft Agent Framework python-1.26.0](https://github.com/microsoft/agent-framework/releases/tag/python-1.26.0)** (Nov 13, at the edge of the window). The core package picks up `loop_return_final_only` on `create_harness_agent()`, so non-streaming callers can get just the final loop response. The breaking change to read before upgrading is in the GitHub Copilot integration, which now refuses to start unless GitHub Copilot CLI is 1.0.85 or later. The Hyperlight sandbox also gets a default 30-second execution budget, so long-running guest code needs a bigger `execution_timeout_seconds`.

```bash
pip install -U "agent-framework-core>=1.26.0"
```

**[NVIDIA cuda-pathfinder 1.9.0](https://github.com/NVIDIA/cuda-python/releases/tag/cuda-pathfinder-v1.9.0)** (Nov 13). This is the small utility that helps Python code locate CUDA libraries on a machine, which saves you from hand-building library paths when things go missing. The release page links to full notes, and I didn't read those, so treat the rest as unverified. It's also on conda-forge if that's how your environment is built.

```bash
pip install "cuda-pathfinder==1.9.0"
```

**boto3 1.44.3** (Nov 13). AWS's Python SDK was tagged on the 13th. The GitHub release page has no notes, so I can't tell you what changed. If you pin boto3 in production, check botocore's changelog before you bump it.

## Open source libraries

**[langchain-openai 1.8.0](https://github.com/langchain-ai/langchain/releases/tag/langchain-openai%3D%3D1.8.0)** (Nov 13). The new feature is `OpenAIClassifier`, which wraps OpenAI's GA Decisions API. The change that will catch some people is the Python floor: 3.10 is dropped, and the package now needs `langchain-core` 1.8.0 or newer. If you're still on 3.10, pip will quietly keep you on 1.7.x.

```bash
pip install -U "langchain-openai==1.8.0"
```

**[LlamaIndex v0.14.26](https://github.com/run-llama/llama_index/releases/tag/v0.14.26)** (Nov 13). The Anthropic integration adds Claude Sonnet 5.5 and Haiku 5.5, and registers claude-opus-5-5. The Bedrock Converse integration gets the same Claude models plus the GPT-6 family, and the OpenAI package picks up GPT-6 Astra, Sol and Luna. The release also raises `requires-python` across most integrations as a security fix, so check your interpreter version before upgrading.

```bash
pip install -U "llama-index-llms-anthropic==0.12.3"
```

**[langchain-core 1.8.1](https://github.com/langchain-ai/langchain/releases/tag/langchain-core%3D%3D1.8.1)** (Nov 15). A small release with one feature: a per-context LangSmith gateway override, `langsmith_gateway`. The rest is maintenance and a dependency bump. If you route traces through a gateway, this is the one to read.

Also on Nov 15, the `langchain-groq`, `langchain-mistralai`, `langchain-deepseek` and `langchain-xai` packages were each bumped to 1.x releases. I didn't read their notes, so I'm only listing them so you know they moved.

vLLM also published two release candidates, [v0.34.0rc3](https://github.com/vllm-project/vllm/releases/tag/v0.34.0rc3) (Nov 13) and [v0.34.0rc4](https://github.com/vllm-project/vllm/releases/tag/v0.34.0rc4) (Nov 14). The notes I could reach were too thin to summarize, so I'd wait for the final release before reading anything into them.

## Worth trying today

If you use langchain-openai, check whether your environment can take the new version before you upgrade anything else. This dry run tells you without changing your install.

```bash
python --version
pip install --dry-run "langchain-openai==1.8.0"
```

If the dry run fails with a Python version error, that's the 3.10 floor showing up.
