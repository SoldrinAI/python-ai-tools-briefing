# AI tools and libraries on Python: 2026-11-24

It's a quiet day. Only a handful of Python AI packages moved between Nov 22 and Nov 24 that I could tie to release notes, so I left out the rest instead of guessing. The Anthropic and LiteLLM updates are the ones to read first, and the Ray patch carries a security fix.

## Enterprise tools

**[Anthropic Python SDK 2.13.0](https://github.com/anthropics/anthropic-sdk-python/releases/tag/v2.13.0)** (Nov 23). The headline is that Claude Opus 4.5 is now marked deprecated, with an end-of-life date of January 22, 2027. If your code still pins it, start the move now rather than in January. The release also adds External Storage to the Admin API beta, with webhook events for storage failures and recovery.

```bash
pip install -U "anthropic==2.13.0"
```

**[OpenAI Python SDK 3.58.0](https://github.com/openai/openai-python/releases/tag/v3.58.0)** (Nov 23). The one feature is an API for setting and reading agent session spending limits. The notes don't say which endpoints take the limit, so check the SDK docs before you wire it into an agent loop. A fix also clarifies when you can leave out the completion choice count.

```bash
pip install -U "openai==3.58.0"
```

**[Databricks SDK for Python 0.170.0](https://github.com/databricks/databricks-sdk-py/releases/tag/v0.170.0)** (Nov 23). Mostly new serverless compute policy calls and a data classification rescan. For AI work, the AI Search scaling phase gets a `finalizing` value. The notes also flag `Rule.schedule` in the lakewatch service as no longer required and marked breaking, so read that part if you use it. Worth a look if you're on Databricks, less so otherwise.

```bash
pip install -U "databricks-sdk==0.170.0"
```

## Open source libraries

**[LiteLLM 1.108.16](https://github.com/BerriAI/litellm/releases/tag/v1.108.16)** (Nov 23). This is a patch on the 1.108 LTS line, and it has breaking changes in several provider paths. Anthropic requests now send `extra_body` fields at the top level, Vertex AI sends the caller's `anthropic-version` in the Claude request body, and MCP gateway dynamic client registration is now opt-in. If you pinned 1.108.15 yesterday, test those routes before you move to this one.

```bash
pip install -U "litellm==1.108.16"
```

**[Ray 2.60.1](https://github.com/ray-project/ray/releases/tag/ray-2.60.1)** (Nov 23). A patch release with a security fix: brotli moves to 1.2.1 to close CVE-2026-111497. Ray now creates `~/.ray/auth_token` with `0600` permissions, but files from earlier versions keep their old permissions. `read_delta` also takes a new `partition_filters` argument, and it now rejects column-mapped Delta tables.

```bash
pip install -U "ray==2.60.1"
```

**[browser-use 1.0.8](https://github.com/browser-use/browser-use/releases/tag/1.0.8)** (Nov 22). Mostly agent fixes. On a headless machine with no API key, a run now prints a link and a code you can approve from another device, instead of stalling. `Browser(cdp_url=...)` attaches to the page you already have open rather than opening a blank tab, which helps if you drive a browser you've already signed into.

```bash
pip install -U "browser-use==1.0.8"
```

## Worth trying today

Ray 2.60.1 tightened the permissions on its auth token file, and older installs keep the loose ones. Check whether you have one, and fix it if you do. If the file doesn't exist, you're fine.

```bash
pip install -U "ray==2.60.1"
ls -l ~/.ray/auth_token && chmod 600 ~/.ray/auth_token
```
