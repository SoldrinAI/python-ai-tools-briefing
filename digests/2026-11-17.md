# AI tools and libraries on Python: 2026-11-17

Most of the releases I could verify from the last two days were tagged on November 16, and several big projects had nothing new in the window, so this one is shorter than usual. Every link below goes to a release page I opened, and I've noted where the notes were too thin to say more.

## Enterprise tools

**[Anthropic Python SDK v2.9.0](https://github.com/anthropics/anthropic-sdk-python/releases/tag/v2.9.0)** (Nov 16). The thing to act on here is cleanup. Several beta header values are now deprecated, including `prompt-caching-2024-07-31` and `pdfs-2024-09-25`, and the release says a later version will drop them. Search your code for them before that upgrade catches you off guard. Most of the rest is fixes to the agent toolset's grep tool and file path handling.

```bash
grep -rnE "prompt-caching-2024-07-31|pdfs-2024-09-25|token-counting-2024-11-01" .
```

**[Google Gen AI SDK v3.4.0](https://github.com/googleapis/python-genai/releases/tag/v3.4.0)** (Nov 16). Adds batch inputs and usage metadata for Gemini embedding models on the Gemini Enterprise API, along with tool search types for Interactions. Names outside `google.genai.interactions` are deprecated now, so check your imports if you use Interactions. The async client also got several fixes, including keeping one connection pool per event loop, which matters if you run it under more than one loop.

```bash
pip install -U google-genai
```

**[Snowflake ML Python 2.10.0](https://github.com/snowflakedb/snowflake-ml-python/releases/tag/2.10.0)** (Nov 16). Model monitors can now target a model's inference table. To do that, leave `source` off `ModelMonitorSourceConfig`, because setting it points the monitor at something else. The release also fixes deployments of model files with spaces or quotes in their names, which used to fail during the inference service's model download. The notes don't include a usage example, so check the package docs before copying the config.

```bash
pip install -U snowflake-ml-python==2.10.0
```

**[azure-ai-agentserver-activity 1.0.0](https://github.com/Azure/azure-sdk-for-python/releases/tag/azure-ai-agentserver-activity_1.0.0)** (Nov 16). The first stable release of this Azure package. It captures original-subject assertions from platform headers and returns a classified error when that attribution is malformed, before the Activity handler runs. It needs azure-core 2.3.0 or later.

```bash
pip install azure-ai-agentserver-activity==1.0.0
```

## Open source libraries

**[vLLM v0.34.0](https://github.com/vllm-project/vllm/releases/tag/v0.34.0)** (Nov 16). The release adds ten new models, including Mistral Large 4 and several NVIDIA speech models. Two defaults changed that can break an existing setup. The extensible KV cache is now on by default on CUDA and ROCm, and `--block-size` defaults to 64 instead of 16. Model Runner V1 is also gone, so setting `VLLM_USE_V2_MODEL_RUNNER=0` now fails at startup. If you want the old block size back, pass the flag explicitly.

```bash
vllm serve <your-model> --block-size 16
```

**[Databricks SDK for Python v0.167.0](https://github.com/databricks/databricks-sdk-py/releases/tag/v0.167.0)** (Nov 16). The headline is a configurable HTTP adapter for custom transports, including mutual TLS, which applies to API calls and to the first request to `/.well-known/databricks-config`. The notes don't walk through the setup, so read the SDK docs before you rely on it. The same release adds a statement execution v2 service and methods for app deployment scan findings.

```bash
pip install -U databricks-sdk==0.167.0
```

**[LangChain core 1.8.1](https://github.com/langchain-ai/langchain/releases/tag/langchain-core%3D%3D1.8.1)** (Nov 15). The new piece is a per-context LangSmith gateway override. The same day, the partner packages for Groq, Mistral, DeepSeek and xAI each moved to a release that routes their chat classes through the LangSmith gateway (see the [LangChain releases page](https://github.com/langchain-ai/langchain/releases) for the exact versions). If your traces go through a gateway, check the routing after you upgrade.

## Worth trying today

See which of these packages your environment already pulls in, and whether any of them are pinned to something older.

```bash
pip show anthropic google-genai databricks-sdk vllm
```
