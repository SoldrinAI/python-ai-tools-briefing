# AI tools and libraries on Python: 2026-11-26

Nothing new this window, just new versions of libraries you probably already have installed, and a couple of them break things. The one to know about is pydantic-ai's change to empty model responses, which matters if you run fallback models.

## Enterprise tools

**[Databricks SDK for Python 0.171.0](https://github.com/databricks/databricks-sdk-py/releases/tag/v0.171.0)** (Nov 25). This one adds a `geniemigrate` package and a workspace-level `w.genie_migrate` service, along with new `resources` and `text_instruction` fields on the Genie agent types. It also removes some fields that were in use: `data_sources` from `GenieAgentDefinition`, and `sql_functions` and `text_instructions` from `GenieAgentInstructions`. If your code builds Genie agents, grep for those names before you bump the pin.

```bash
pip install -U "databricks-sdk==0.171.0"
```

**[Mistral AI Python client 3.9.0](https://github.com/mistralai/client-python/releases/tag/v3.9.0)** (Nov 24). A big cleanup of the beta surface: 122 items were removed, including `ContextSearchIndexes` and `RagSearchIndexes`. `import_from_playground()` is gone from the observability datasets, while `create_records()` is new. There are also new turn events for audio transcription streaming (`turn.start`, `turn.end`, `turn.eager_end` and `turn.resume`), which is handy if you stream transcription.

```bash
pip install -U "mistralai==3.9.0"
```

## Open source libraries

**[pydantic-ai 2.75.0](https://github.com/pydantic/pydantic-ai/releases/tag/v2.75.0)** (Nov 25). The useful addition is `RunContext.submit_output()`, which lets a tool hand back the run's final output directly. The compatibility change is the one to read: empty or unreadable model responses now raise `ModelEmptyResponseError` or `ModelInvalidResponseError`, and fallback models retry on them by default. If you had custom retry logic for empty replies, check that it does not now run twice.

```bash
pip install -U "pydantic-ai==2.75.0"
```

**[LiteLLM 1.111.0](https://github.com/BerriAI/litellm/releases/tag/v1.111.0)** (Nov 25). Adds `claude-fable-5-2` across the Anthropic, AWS, Vertex AI and Azure entries, and a customer, team and member hierarchy with budget templates on the proxy. Anthropic Messages is now served on the Rust path only. The breaking part is billing: transcriptions are charged by the seconds the provider reports, so any cost dashboard that totals transcription spend will shift.

```bash
pip install -U "litellm==1.111.0"
```

**[langchain-core 1.8.5](https://github.com/langchain-ai/langchain/releases?q=%22langchain-core%3D%3D1%22)** (Nov 25). A small release with one fix that matters if you stream: later stream chunks now reuse the provider's message ID instead of minting a new one. If you key UI state on message IDs during streaming, this is the change to test.

```bash
pip install -U "langchain-core==1.8.5"
```

## Worth trying today

Pin pydantic-ai in a scratch environment and check your fallback chain. Point your primary model at something that will return an empty or malformed reply, then confirm the request moves to the fallback as you expect.

```bash
python -m venv .venv-digest && . .venv-digest/bin/activate
pip install -U "pydantic-ai==2.75.0"
python -c "import pydantic_ai; print('ok')"
```
