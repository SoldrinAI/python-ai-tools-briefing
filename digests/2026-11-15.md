# AI tools and libraries on Python: 2026-11-15

A quiet stretch. The releases I could verify and haven't covered yet all landed on November 12, right at the edge of the 48-hour window, so I've marked them as such.

## Enterprise tools

**[google-genai 3.3.0](https://github.com/googleapis/python-genai/releases)** (Nov 12, just outside a strict 48-hour window). This is Google's official Python SDK for Gemini and the Gen AI APIs. The release adds `XHIGH` to `ThinkingLevel`, a few new `FinishReason` values, and `gemini-4-hydrogen` to the model enum. No breaking changes are listed. If your code compares finish reasons or passes thinking levels as strings, the new values are worth a look.

```bash
pip install -U "google-genai==3.3.0"
```

## Open source libraries

**[pydantic-ai 2.68.0](https://github.com/pydantic/pydantic-ai/releases/tag/v2.68.0)** (Nov 12, also at the edge of the window). This one has more breaking changes than usual, so read the notes before you upgrade. In `pydantic_ai_harness`, `num_results` becomes `max_results` and `max_duration_secs` becomes `max_duration_seconds`. Sub-agent task events and `CapabilityEvent` fields were renamed, and the old names remain as deprecated aliases. The behavior change that could bite you most: `ModelFallback` now moves on to the next model when a response is cut off at `max_tokens`, so code that relied on the truncated output will behave differently.

```bash
pip install -U "pydantic-ai==2.68.0"
```

Transformers 5.23.0 and openai 3.51.0 both shipped on November 13, but they were covered in yesterday's digest, so I'm not repeating them here.

## Worth trying today

Before you upgrade anything that uses pydantic-ai's harness, search your code for the renamed arguments and for the `AskUser` name, which has moved into the deferred pipeline.

```bash
grep -rn "num_results\|max_duration_secs\|AskUser" --include="*.py" .
```
