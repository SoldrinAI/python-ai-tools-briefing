# AI tools and libraries on Python: 2026-11-28

Another quiet window. I could confirm one enterprise release and two open source releases from the last two days, and I left out anything I couldn't check on its release page. The pydantic-ai 2.76.0 and openai-python 3.60.0 releases from Nov 26 were in yesterday's digest, so I skipped them here.

## Enterprise tools

**[azure-mgmt-search 10.0.0](https://github.com/Azure/azure-sdk-for-python/releases/tag/azure-mgmt-search_10.0.0)** (GitHub shows Nov 26, the changelog says Nov 1). This is the management SDK for Azure AI Search. The release is a breaking one. Service fields such as `endpoint`, `status` and `replica_count` now sit under a `properties` object, `check_name_availability` takes its name inside `check_name_availability_input`, and the `search_management_request_options` parameter is gone from about 25 operations. If you script provisioning, expect your code to break on the first run, so read the migration guide the changelog links to before you bump the pin.

```bash
pip install -U "azure-mgmt-search==10.0.0"
grep -rn "search_management_request_options\|check_name_availability" --include="*.py" .
```

## Open source libraries

**[pydantic-ai 2.77.0](https://github.com/pydantic/pydantic-ai/releases/tag/v2.77.0)** (Nov 27). The big addition is conversation storage. `ConversationStore` now has SQLite, Postgres and MongoDB backends, which means you can keep agent history somewhere durable without writing your own store. The rename to watch is `SqliteConversationStore` becoming `SqliteSessionStore`. The old name still imports but emits a deprecation warning, so it's a good time to fix it before the warning turns into a failure.

```bash
pip install -U "pydantic-ai==2.77.0"
grep -rn "SqliteConversationStore\|ConversationConflict" --include="*.py" .
```

**[Strands Agents Python 1.68.0](https://github.com/strands-agents/harness-sdk/releases/tag/python%2Fv1.68.0)** (Nov 27). Strands is AWS's open source agent SDK. This release makes `manage_background_task` the default harness behavior, and the maintainers marked that as breaking. It also adds an `acceptedMimeTypes` field to model info, so `ModelProxy` drops media a model can't take instead of sending it. Fixes for OpenAI Responses reasoning across stateless turns and for Claude and Gemini signed reasoning are worth a look if you use those models through Strands. I couldn't load the PyPI page to confirm the package version, so check the tag page for the install name before you pin it.

## Worth trying today

Pick one of the two breaking changes above and run your test suite with deprecation warnings turned into errors. That tells you which of your calls will break before the upgrade does.

```bash
python -W error::DeprecationWarning -m pytest -q
```
