# AI tools and libraries on Python: 2026-11-14

A quiet day with few new releases. The one to read first is transformers 5.23.0, which changes how models get exported and removes a few names you might be importing.

## Enterprise tools

**[openai 3.51.0](https://github.com/openai/openai-python/releases/tag/v3.51.0)** (Nov 13). The notes are short: agent, image, Live and external key support were expanded, and no breaking changes are listed. This is a 3.x minor after 3.50.0 on Nov 12, so if you use the Live or image helpers, it's worth a quick look at the diff. Nothing in the release notes says what the new surface looks like, so read the code rather than guess.

```bash
pip install -U "openai==3.51.0"
```

**[google-adk 2.14.1](https://github.com/google/adk-python/releases/tag/v2.14.1)** (Nov 12). A small one: it turns off FastAPI's built-in tracing when the agent runs on Agent Engine. If you deploy ADK agents to Vertex AI Agent Engine and noticed extra FastAPI spans in your traces, this is the change that removes them.

```bash
pip install -U "google-adk==2.14.1"
```

## Open source libraries

**[transformers 5.23.0](https://github.com/huggingface/transformers/releases/tag/v5.23.0)** (Nov 13). The headline is the exporter overhaul. `export()` now returns an `ExportedModel` that you can call like the original model, push to the Hub, and reload on its backend (ONNX Runtime, OpenVINO, Dynamo or ExecuTorch). The breaking changes are the part to check first: the `output_path` options on the exporter are gone in favor of `save_pretrained`, `ep_router` is removed, and the `[audio]` extra no longer pulls in librosa or phonemizer. New models include LFM3-Text, LFM3-VL and Dots 3 Note Preview.

```bash
pip install -U "transformers==5.23.0"
```

**[gradio 6.32.0](https://github.com/gradio-app/gradio/releases/tag/gradio@6.32.0)** (Nov 12). The change to know about is that the MCP server now requires login when the app has auth turned on. If you expose a Gradio app as an MCP tool, check that your clients can still authenticate. Workflows picked up depth estimation and 3D model nodes, and the webcam component now shows an error when camera permission is denied.

```bash
pip install -U "gradio==6.32.0"
```

**[llama-index-core 0.14.26](https://github.com/run-llama/llama_index/releases)** (Nov 13). A maintenance release. It fixes a `langchain-community` deprecation that broke the LangChain bridge imports, and it picks up Python dependency security updates. If your code imports through the LangChain bridge and started failing after a dependency bump, this is the one to try.

```bash
pip install -U "llama-index-core==0.14.26"
```

## Worth trying today

If you use transformers' exporter anywhere, search your code for the old `output_path` argument and for calls to `export(`. The return type has changed, so a script that expects a file path back will fail in a confusing way.

```bash
grep -rn "output_path\|\.export(" --include="*.py" .
```
