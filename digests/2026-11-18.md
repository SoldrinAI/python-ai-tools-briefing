# AI tools and libraries on Python: 2026-11-18

Quiet window again, so this one is short. Everything below shipped on November 16 or 17, and I checked each release page or the PyPI upload time before listing it.

## Enterprise tools

**[Anthropic Python SDK v2.10.0](https://github.com/anthropics/anthropic-sdk-python/releases/tag/v2.10.0)** (Nov 17). The new beta `billing_policy` request parameter is the one to look at, along with new error codes for contract spend limits and billing refusals. If you map API errors to messages for users, add those codes. Older error model names are deprecated rather than removed, so the upgrade itself should be quiet. One change will shift your logs: failed aiohttp connections are no longer reported as timeouts.

```bash
pip install -U anthropic==2.10.0
```

**[OpenAI Python SDK v3.53.0](https://github.com/openai/openai-python/releases/tag/v3.53.0)** (Nov 17). Adds model identifiers for GPT-6.2 Astra, GPT-6.2 Astra Law (Responses) and GPT-6.2 Sol, plus background windows of 2 and 8 hours for the Responses API. No breaking changes are listed. A follow-up release, v3.54.0, the same day only adds type definitions for budget events in Managed Agents, so skip it unless you use that feature.

```bash
pip install -U openai
```

## Open source libraries

**[pydantic-ai 2.70.0](https://github.com/pydantic/pydantic-ai/releases/tag/v2.70.0)** (Nov 17). The headline is two high-severity fixes in the harness package (pydantic-ai-harness 0.70.0): a slow ANSI-stripping path in `ToolOutputLimits`, and a slow JWT redaction pattern that also stopped matching JWTs whose header contains `-eyJ`. If you use the harness, upgrade for those. The release also adds `StreamGuardrail`, `PruneToolResults`, `RetryOnModelErrors`, `ToolSearch` and `check_task` for background delegations. If you are jumping from before 2.69.0, read that release too, since it renamed `DockerSandbox` to `DockerContainer` (the old name stays as an alias).

```bash
pip install -U pydantic-ai==2.70.0
```

**[LiteLLM 1.108.11](https://github.com/BerriAI/litellm/releases/tag/v1.108.11)** (Nov 17, LTS line). Mostly fixes across Azure, Bedrock, Vertex AI and Gemini, Cohere and OpenRouter, plus proxy memory use under retries. Check two things before you upgrade. Only proxy admins can now write `os.environ/` values in team model configs, so team admins get a 403. The UI image also moved to slim nginx, which drops `curl`, so any health check that calls curl inside that container will need a change.

```bash
pip install -U litellm==1.108.11
```

**[langchain-core 1.8.2](https://github.com/langchain-ai/langchain/releases/tag/langchain-core%3D%3D1.8.2)** (Nov 17). `langsmith_gateway` now accepts custom headers and bypasses proxy settings, which helps if your traces go out through a corporate gateway. There is also a race condition fix in warning-filter handling during schema creation. The same day, langchain-openai 1.8.1 shipped a fix so function call arguments are recovered from "done" events.

```bash
pip install -U langchain-core==1.8.2
```

## Worth trying today

See which of these packages are behind in your environment. It takes a few seconds and tells you whether any of the versions above are newer than what you have pinned.

```bash
pip list --outdated | grep -iE "^(openai|anthropic|pydantic-ai|litellm|langchain-core) "
```
