# AI tools and libraries on Python: 2026-11-27

A quiet window. Most of what shipped in the last two days is point releases, and the ones that matter for your code are mostly breaking changes or deprecations, not new features. I kept only the items I could confirm on their release pages.

## Enterprise tools

**[openai-python 3.60.0](https://github.com/openai/openai-python/releases/tag/v3.60.0)** (Nov 26). Adds spend alerts and response compaction fields, and support for updating session vaults. Spend alerts are the part a team lead will ask about. The release page doesn't list parameter names, so read the SDK docs before you build on them.

```bash
pip install -U "openai==3.60.0"
```

**[Strands Agents Python 1.67.0](https://github.com/strands-agents/harness-sdk/releases/tag/python%2Fv1.67.0)** (Nov 25). Adds `HttpDecisionModel`, which lets Strands use any System One HTTP server as its decision model. The breaking part is the context manager, which is out of experimental now, with `stash` renamed to `archive`. If you upgrade without changing that, the old name will fail, so search your code first.

```bash
grep -rn "stash" --include="*.py" .
```

**[Google ADK 2.15.1](https://github.com/google/adk-python/releases/tag/v2.15.1)** (Nov 25). A patch release with no new features. The fix that matters if you run ADK with Claude models is the one for Claude sampling settings on Anthropic 1.x and 2.x clients. The others cover RemoteA2aAgent streaming and dynamic instruction routing.

```bash
pip install -U "google-adk==2.15.1"
```

## Open source libraries

Only one release in this window that I could confirm on its release page, so this section is short.

**[pydantic-ai 2.76.0](https://github.com/pydantic/pydantic-ai/releases/tag/v2.76.0)** (Nov 26). Tools can now change in the middle of a realtime session through `UpdateTools`. The change to watch is Gemini. `gemini-2.5-pro` and `gemini-2.5-flash` now emit a `DeprecatedModelWarning`, so anything running with `filterwarnings = error` will fail on those calls. The release also makes `read_file` offsets 1-indexed, so an offset of `N` becomes `N + 1`.

```bash
pip install -U "pydantic-ai==2.76.0"
```

## Worth trying today

```bash
grep -rn "gemini-2.5" --include="*.py" .
```
