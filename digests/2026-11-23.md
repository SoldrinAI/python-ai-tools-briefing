# AI tools and libraries on Python: 2026-11-23

It's a quiet day. Between Nov 21 and now, the only AI-relevant releases I could verify are two LiteLLM builds and a routine AWS SDK update, so this digest is short. The LiteLLM 1.108.15 LTS release has a breaking change for keyless provider configs, which is the one to read before you upgrade anything.

## Enterprise tools

Not much landed here. Azure's azure-appconfiguration 1.10.1 (Nov 22) isn't AI-related, Databricks' SDK 0.169.0 is from Nov 19, and Bedrock AgentCore SDK 1.27.0 came out Nov 20 at 21:33 UTC, just outside the window. Google, Snowflake and NVIDIA had nothing I could confirm.

**[boto3 1.44.9](https://pypi.org/project/boto3/1.44.9/)** (Nov 21). The AWS SDK for Python is mostly service plumbing this time. The item that matters for ML work is new SageMaker AI APIs for viewing capacity reservations and their usage, which helps if you're tracking GPU spend. The release also has a QuickSight update.

```bash
pip install -U "boto3==1.44.9"
```

## Open source libraries

**[LiteLLM 1.108.15](https://github.com/BerriAI/litellm/releases/tag/v1.108.15)** (Nov 21). This is the LTS line, so it's the one to pin if you run the gateway in production. Read the breaking change first: keyless deployments defined in JSON now return a 401 until you set an API key or the provider's key environment variable. The Cohere v2 fixes are useful too. Streamed tool calls no longer arrive as one empty chunk, and `tool_choice` is now respected.

```bash
pip install -U "litellm==1.108.15"
```

**[LiteLLM 1.112.0.dev2](https://github.com/BerriAI/litellm/releases/tag/v1.112.0-dev.2)** (pre-release, Nov 21). A preview of the next minor version. Budgets get one model across keys, teams, users and customers, with custom spend windows and budget alerts. It also has breaking changes, including rejecting `previous_response_id` on chat completions and Messages. Treat it as a scratch-environment test only.

```bash
pip install "litellm==1.112.0.dev2"
```

## Worth trying today

Before you upgrade the gateway, search your deployment config for providers that have no API key set. Those are the ones that will start returning 401 on 1.108.15, and it's much better to find them in a config diff than in an alert.

```bash
python -m venv .venv-litellm && . .venv-litellm/bin/activate
pip install "litellm==1.108.15"
pip show litellm | head -2
```
